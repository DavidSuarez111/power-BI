    What is power BI? 
    self service BI platform,
    desktop and web based applications for 
    connecting, modeling and visualizing data

    Why power BI? 
    It allows you to connect, transform and load millions of rows of data. 
    YOu can build relational models to blend data from multiple sources
    Define complex calculations using Data Analysis Expressions (DAX)
    Bring data to life with interactive reports and Dashboards
    Develop a versatile, in demand skill set

Storage & Connection Modes 
    Import 
    Dataset is less than 1 GB 
    Source data does not change frequently 
    No restrictions o power Query, modeling and DAX. 

    Direct Query 
    Dataset is too large to be stored in memory 
    Source data changes frequently and reports must reflect changes 
    Company policy states that data can only be accessed from the original source

    Composite Model 
    Boost performance by setting appropriate storage for each table 
    Combine a DirectQuery model with additional imported data 
    Create a single model from two or more DirectQuery models

    Live connection 
    create one dataset that serves as a central source of truth 
    Analyst teams can create different analysis from the same dataset 
    multi developer team to advance on separate functions each one changes the data the other visualizes it.

    Data QA & Profiling tools 
    Tools 
        Column quality 
        column distribution 
        column profile 
            So we use this parameters to explore the data prior to loading it into Power Bi

    In the view tab of query editor 
    There is the option to display the quality values of the data by clicking in blank squares which is separated into valid, error and empty. 
        The number of each type of quality can be known by hovering over each percentage and by clicking the options menu or the 3 points we can take actions like removing or keeping duplicates, empty values or errors. 

    Col distribution
        Enumerates the distinct and unique records. 

    Column profile 
        Holistic view and statistics
            Count, 
            Distinct count,
            unique, 
            min and max. 

    Note: the statistics are based on the first 1000 rows one must click on a botton at the left bottom to consider the entire dataset

    To explore the errors click on keep errors and select each. 

    To clean the errors and empty values well click on remove errors then remove empty values. The steps will be registered and can be reverted in the applied steps section. 

    Duplicates can be useful so it is necessary to have awareness before deciding to remove them. But still it is an action that can be clicked.
