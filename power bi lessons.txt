    What is power BI? 
    self service BI platform,
    desktop and web based applications for 
    connecting, modeling and visualizing data

    Why power BI? 
    It allows you to connect, transform and load millions of rows of data. 
    YOu can build relational models to blend data from multiple sources
    Define complex calculations using Data Analysis Expressions (DAX)
    Bring data to life with interactive reports and Dashboards
    Develop a versatile, in demand skill set 

    Excel vs Power Bi 
    Excel
    Spreadsheets, pivot tables, A1 Notation, cell formulas

     Power BI 
     report view, custom visuals, interactive dasboards, power Bi service 

     In common 
     Power Query 
     Data Model 
     DAX 

    Excel and Power Bi are built on top of the same analytics engines. 

    Power Bi takes the same data tranformation and modeling capabilities and adds powerful visualization and publishing tools. 
    Transition is easy. From Excel to powerBi and viceversa.

    Power Bi Workflow 
    1.Extract and transform data in the Power Query editor -Back End
    2.Load the data in the Power Bi - Front End. 
    3.Data View 
    4.Report View
    {Query, Model View, Data View, Report View}

    1. Get data
        Either Excel, SQL, CSV or else. 
    You select your data source from either Get Data button or Transform Data and click on close and apply to load. 

    2. model view. At the left side. 

    3. Data view or table view. 
        Depending on the data that you select different menus will be accesible. i.e. a column or a table.

    4. Report View. 
        Add graphs and visuals in different pages. 

    End of user interface 

    Power Bi is in constant updating, monthly generally so new features may be added. 

Power Bi services allows to publish data and collaborate in real time with peers.
